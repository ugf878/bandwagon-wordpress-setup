## WordPress 安装全流程：六步上线

### 第一步：注册并购买

打开官网（国内访问建议用官方镜像站，DNS 更稳），右上角 Register 注册。两个细节：注册前关掉代理、信息如实填写，否则订单可能被风控判成欺诈；选好套餐进购物车，在 Validate Code 填优惠码，然后选 Alipay 用支付宝付款。付款完成后 VPS 自动开通，SSH 端口信息会发到注册邮箱。

### 第二步：进 KiwiVM 面板装系统

用户中心 → My Services → Open KiwiVM。搬瓦工自家的 KiwiVM 面板里能查 IP 和 SSH 端口、装系统、迁机房、看流量。新机器建议先装 Ubuntu 22.04 或 Debian 12，稳定，出问题也好查资料。

### 第三步：SSH 连上服务器

需要三样东西：IP 地址、SSH 端口、root 密码。搬瓦工默认 SSH 端口不是 22，实际端口号在 KiwiVM 的 Main Controls 页面查——新手连不上服务器，八成是这里出了问题。

Windows 用 Xshell 或 PuTTY，Mac 直接开终端：


ssh root@你的IP -p 端口号


### 第四步：装宝塔面板

命令行装环境对新手太劝退，装个宝塔面板，建站、数据库、SSL 全部图形化操作。Ubuntu/Debian 下执行：


wget -O install.sh https://download.bt.cn/install/install-ubuntu_6.0.sh && sudo bash install.sh ed8484bec


装完记下面板地址和初始密码。登录后按提示装 LNMP 套件，推荐组合：Nginx 1.22+ / MySQL 5.7 / PHP 8.1，等十来分钟。不想用面板的话，LNMP 一键包是替代方案，更省内存，但全程命令行。

### 第五步：添加站点、解析域名

宝塔里「网站 → 添加站点」，填域名、勾选创建数据库（用户名密码记下来，一会儿要用），PHP 选 8.1。然后去域名注册商后台加一条 A 记录，指向 VPS 的 IP。国内注册商买的域名一样能解析过来，备案跟着服务器走，境外服务器不需要备案。解析生效要几分钟到几小时，ping 一下域名验证。

### 第六步：部署 WordPress 并上 HTTPS

宝塔软件商店里有 WordPress 一键部署，全程点鼠标。手动装也不难：下载 latest.tar.gz 解压到网站根目录 /www/wwwroot/你的域名/，把 wp-config-sample.php 复制成 wp-config.php，填进第五步的数据库信息，然后浏览器打开域名，跟着安装向导填站点标题和管理员账号密码，半分钟装完。

上线前补三件事：宝塔站点设置里申请 Let's Encrypt 免费证书并开启强制 HTTPS；后台设置固定链接格式；装个 WP Super Cache 之类的缓存插件。
